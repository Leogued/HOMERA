# Polices de marque HOMERA

Déposer ici le fichier de la police **Cakecafe** (Khurasan) :

- `Cakecafe.woff2` (recommandé) et/ou
- `Cakecafe.ttf`

Elle est utilisée uniquement pour le mot-symbole « HOMERA » via la classe `font-brand`
(voir `app/globals.css`). Tant que le fichier est absent, le logo s'affiche en Playfair Display.
