# Documentation des Composants HOMERA (`docs/components/`)

Ce répertoire décrit les familles de composants réutilisables de HOMERA et leurs contrats :

- **[PRIMITIVES_AND_LAYOUT.md](./PRIMITIVES_AND_LAYOUT.md)** — Primitives UI (`components/ui/*`), en-têtes publics (`Navbar`, `PublicHeader`), pied de page (`Footer`) et coquille d'espace (`WorkspaceShell`, `Primitives`).
- **[CATALOG_AND_HOME.md](./CATALOG_AND_HOME.md)** — Les 9 scènes d'accueil (`components/home/*`), la carte de bien (`PropertyCard`), les filtres (`CatalogFilters`) et la fiche détaillée (`PropertyDetail`).
- **[WORKSPACE_AND_AUTH.md](./WORKSPACE_AND_AUTH.md)** — Composants de formulaire d'authentification (`components/auth/*`) et modules métiers des 4 espaces (`components/workspace/*`, `components/client/*`).
