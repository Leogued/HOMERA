# Documentation des Interactions & Flux (`docs/interactions/`)

Ce répertoire décrit les mécanismes d'interaction, d'état et d'accessibilité de HOMERA :

- **[MOTION_AND_SCROLL.md](./MOTION_AND_SCROLL.md)** — Ordonnanceur `requestAnimationFrame` (`lib/motion-frame.ts`), timelines sticky, inertie de galerie et adaptation `prefers-reduced-motion`.
- **[WORKFLOWS_AND_STATE.md](./WORKFLOWS_AND_STATE.md)** — Persistance locale (`VisitorProvider`, `AuthProvider`, `WorkflowProvider`) et règles de transition entre Client, Propriétaire, Agent et Admin.
- **[ACCESSIBILITY_AND_RESPONSIVE.md](./ACCESSIBILITY_AND_RESPONSIVE.md)** — Navigation clavier, gestion du focus, contrastes WCAG AA et comportement responsive de 320 px à 1 920 px.
